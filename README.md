# Adama LO — Cybersecurity Portfolio

A responsive, English-language cybersecurity portfolio built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder (not the enclosing folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for deployment. Your site will be available at `https://YOUR-USERNAME.github.io`.

## Personalize before publishing
Search the project for `Adama LO`, `Add your professional email`, and social links.
- Replace the generic LinkedIn and GitHub URLs with your profile URLs.
- Add your professional email.
- Review each project description so it accurately reflects work you have completed.
- Add real CTF write-ups and evidence you are allowed to publish.
- Add a CV PDF only if you want it publicly accessible.

## Add write-ups
Create a new HTML page inside `writeups/` (or use Markdown with a static-site generator later), then add a card in `index.html`.
Do not publish flags, credentials, private target data, or challenge solutions if the platform rules prohibit disclosure.
